# Insurance_Charges_Prediction_Linear_Regression_Project

1) Problem Statement
The goal of this project is to predict insurance charges based on features like age, sex, BMI, smoking status, region, and number of children. The project uses linear regression to create an accurate prediction model.

2) Exploratory Data Analysis (EDA)
Cleaned and preprocessed the dataset by handling missing values and visualizing feature distributions.
Analyzed correlations between features and target variable, identifying key relationships (e.g., BMI and charges).
3) Feature Engineering
Applied transformations like normalization and encoding of categorical variables.
Created interaction features to improve model performance.
4) Feature Selection
Used correlation analysis and recursive feature elimination (RFE) to select significant features, removing irrelevant ones.
5) Model Training
Built a linear regression model to predict insurance charges, using selected features for training.
6) Model Evaluation
Evaluated model performance using metrics such as Mean Absolute Error (MAE), R-squared, and Residual plots to assess prediction accuracy.
